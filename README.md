# Password Strength Checker

A responsive, client-side password strength checker built with HTML, CSS and vanilla JavaScript.

## Features
- Live password strength feedback and progress meter
- Checks length, lowercase, uppercase, number and special character
- Show/hide password control
- Responsive layout for desktop and mobile
- No backend, network request, or password storage

## Run the project
1. Extract the ZIP file.
2. Open the `password-strength-checker` folder.
3. Double-click `index.html` to open it in a browser.

You can also use the VS Code Live Server extension and choose **Open with Live Server**.

## Important note
This is an educational mini-project, not a complete password security audit. The score is a simple client-side heuristic. Do not enter a real password you currently use; test with sample passwords only.
